# Джерела й ліцензії

Правило: ліцензію читаємо на сторінці самого джерела; «лише некомерційне» не беремо. Підпис, якого вимагає ліцензія, стоїть у картці й у «Про програму». Розвідка — `docs/research/SOURCES.md`.
