# Джерела й ліцензії

Правило: ліцензію читаємо на сторінці самого джерела; «лише некомерційне» не беремо. NHS не беремо: його умови забороняють називати NHS джерелом зміненого чи перекладеного тексту (рішення 28.11). Підпис, якого вимагає ліцензія, стоїть у картці й у «Про програму». Розвідка — `docs/research/SOURCES.md`.
