# Речення джерел

Тут — дослівні речення джерел, за якими написано кожну картку (`<розділ>.md`) і тексти словників, що кажуть про факти (`notices.md`). Речення під номерами екстреної допомоги — у самих даних, `src/data/emergency.json` (їх звіряє `src/core/emergency.test.ts`). Тексти самих джерел збережено в `docs/sources/<id>.txt`; реєстр джерел — `src/data/sources.json`.

Будова файлу:

```
## <id картки чи позначки>
Джерело: <id джерела>
> речення джерела, слово в слово
> ще одне
```

Тест `src/core/topics.test.ts` перевіряє: кожне речення є в тексті свого джерела; кожна картка має тут свій запис із реченнями свого джерела; кожне джерело записано в реєстрі з ліцензією, яку програма може використовувати.
