# Позначки над картками — речення джерел

Як читати: під заголовком — те, що написано за джерелом; «Джерело:» — id із `src/data/sources.json`; рядки з `>` — речення джерела дослівно. Тест `src/core/topics.test.ts` звіряє кожне з текстом джерела в `docs/sources/<id>.txt`.

Позначка 112 у картках першої допомоги (`notices.call112`): українською — за наказом МОЗ, англійською й угорською — за сторінкою Єврокомісії (угорською — переклад: угорська версія сторінки Єврокомісії — машинний переклад, про що сказано на ній самій).
