## Відкрите

- Особистий путівник власника (рішення 27.11): окремий закритий репозиторій і адреса за Cloudflare Access — потрібен окремий план; адресу погодити із сесією сайту.
- Після злиття: Дмитро створює воркер `way1ong-survival` у Cloudflare (`docs/cloudflare.md`), далі — `npm run check:live` і перевірка на телефоні (встановлення, без інтернету).
- ECDC (кліщі в Європі, CC BY 4.0) відповідає 429 і 28.11 — не обходили; кліщі поки за CDC (США).
- NHS для карток не годиться: його умови забороняють називати NHS джерелом перекладеного тексту (рішення 28.11).
- Не знайдено: гірський сигнал лиха (усі знайдені джерела — лише некомерційні), угорські оригінали першої допомоги, картка 112 українською (закон про систему 112 ще не прочитано).
